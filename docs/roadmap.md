# 路线图

## 本迭代

- 周课表、东秦固定节次、精简校园入口。
- 登录路由、账号数据隔离、成绩及课表快照、三栋教学楼的公共七日空教室快照。
- 学期 GPA 优先直显，缺少时按东秦规则计算。
- CampusAccess 资源登记与直连策略，独立 WebVPN 会话管理、空闲设置、模拟协议测试和官方浏览器入口。

## 真机验收

- 用新版 Android APK 复验登录后自动进入课表，以及四个标签的切换状态。
- 在 Android 真机验证个人教务数据的首次读取、已登录会话刷新和会话到期重连，并核实调课、重复考核和教务 GPA 字段。
- 在真机验证三栋楼的公共空教室快照、日期切换及离线缓存恢复。
- 在 Android 真机及 iOS 上验证登录回调、ICS 课表导出和提醒投递。
- 复验校园卡充值跳转和相机授权。确认学校扫码是否依赖微信小程序，再决定是否接入原生扫码。
- 在校内和校外用学校允许的真实账号验证官方浏览器 WebVPN、设备验证及单终端挤下线行为。原生适配在取得接入许可、真实授权链接和协议证据后单独验收。

## 校方数据接入后

- 获取校方正式接口后切换到版本化的数据源，并验收同步频率及历史学期覆盖。
- 先接入一个经过确认的只读校园资源，再评估校园网自助、图书馆借阅和一网通办。涉及预约、充值或表单提交的功能由独立业务流程管理。
