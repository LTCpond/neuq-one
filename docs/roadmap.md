# 路线图

## 本迭代

- 周课表、东秦固定节次、精简校园入口。
- 登录路由、账号数据隔离、成绩及课表快照、三栋教学楼的当日空教室界面。
- 学期 GPA 优先直显，缺少时按东秦规则计算。

## 真机验收

- 用新版 Android APK 复验登录后自动进入工作台。
- 在 Android 真机验证首次读取、已登录会话刷新和会话到期重连。核实调课、重复考核、教务 GPA 字段与三栋楼的查询结果。
- 在 Android 真机及 iOS 上验证登录回调、ICS 课表导出和提醒投递。
- 复验校园卡充值跳转和相机授权。确认学校扫码是否依赖微信小程序，再决定是否接入原生扫码。

## 校方数据接入后

- 获取校方正式接口后切换到版本化的数据源，并验收同步频率及历史学期覆盖。
