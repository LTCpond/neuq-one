# 架构

## 会话与本地数据

- GoRouter 检查 `SchoolSession`，未登录时跳转登录页，恢复会话或登录成功后进入课表。旧根路径 `/` 重定向到 `/timetable`。课表、成绩、服务和我的各自保留导航栈，退出或切换身份时重新创建。
- `SchoolAuthRepository` 通过 `NeuqClient` 使用学校统一身份认证。凭据只提交到已核实的学校 HTTPS 认证表单。校方要求额外验证时停止当前登录，并可在系统浏览器访问官方教务。确认教务页的退出入口和学号后，使用原有派生标识隔离本地数据。
- FlutterSecureStorage 保存用于离线恢复的派生标识。Android 在用户选择记住密码后加密保存已验证的学校凭据，供重新启动或教务会话过期时续登。教务 HTTP Cookie 保存在内存。退出时清除本地登录记录和会话。
- 校园卡页面和后台余额读取使用同一套校园卡网页认证流程。网页跳转统一认证时，尝试用当前账号的 CAS 会话获取校园卡专用票据，由校园卡网页完成回跳。校方要求额外验证时，用户可在校园卡页完成。校验网页学号后按账号保存余额和读取时间，失败时保留旧结果。
- Drift schema 2 为旧成绩补充记分方式并添加教务快照表。登录后 SQLite 文件按账号标识隔离；旧版单设备数据库文件保留，不自动并入当前账号。
- 应用通过 Repository 读写数据。学期、课程和成绩保存在本机，按账号隔离。同步失败时保留已有快照。数据库保留旧版考试记录。

## 教务数据

- `SchoolDataSource` 在 Android 和 iOS 上通过已验证的 `NeuqClient` 会话读取学校固定 HTTPS 路径。会话过期时优先用仍有效的统一认证会话恢复。若需密码且本机已保存，尝试一次续登。同步失败保留上一份快照。
- 课表和成绩快照经校验后原子写入，按类型保存最后成功同步时间。尚未同步、确认空数据和刷新失败分别表示。并发刷新共用一次在途请求。教务学期及记录使用稳定的 `school:` 标识，成绩行的 ID 对应单次考核，补考和重修可并存。
- 点击课表或成绩栏时自动请求教务刷新，同时展示最近成功结果。学期 GPA 优先采用教务值，缺少时按对应入学年级的东秦办法以学分加权计算。累计 GPA 采用教务快照。
- 已认证的导航层在应用恢复前台时同步课程提醒并刷新教务课表，停留在其他标签时也会触发。课表按北京时间在午夜和应用恢复前台时更新日期，默认跟随当前教学周。

## 公共数据与静态资源

- `PublicDataClient` 通过 Riverpod 提供。数据层在请求时指定数据源。空教室请求使用 `neuq-one-data`，校园地图、学校政策和 App 版本请求使用 `neuq-one-assets`。公共 HTTP 客户端不需要学校会话，统一处理超时、响应大小、条件请求和重定向限制。[接口和构建配置](public-data.md)
- 空教室使用北京时间七日快照。完整快照和 HTTP 验证信息保存在设备级 Drift 缓存中，刷新失败时按日期匹配缓存。工学馆按房间编号识别楼层，特殊编号在「其他」显示。蓝色由六个有效时段的交集得出，红色依据下个有效时段的结果。过期与不可用时段分别提示。[学校考场楼层示例](https://www.neuq.edu.cn/__local/0/AC/7C/27F1AF02BE447A8B94252250A28_D7F15FCF_2F938.pdf)
- 地图和政策缓存保留原文件。静态站切换后仍可离线显示旧版已验证的地图，首次联网从新源读取完整 PNG 并保存该站点的 HTTP 验证信息。政策目录缓存继续可用，PDF 按目录的 SHA-256 校验。
- 检查更新时读取静态站版本清单，按版本号比较 Android 或 iOS 已安装包。用户可在系统浏览器打开 GitHub Release 页面。[部署与正式发布](deployment.md)

## 日历和界面

- 周视图在左上角选择教学周，在右上角切换学期。节次轴显示每节的开始和结束时间。教务数据按每周独立合并同一教学安排的连续节次，课程块与节次轴使用同一行高。
- 课表页的教务学期来自同步或本地缓存。旧版手动课表可以继续查看、编辑已有课程和导出，编辑保存时选择学校发布的 12 个固定节次。
- 差异化空、加载和失败状态由页面处理。查询失败或离线时，课表和成绩继续显示该账号上次成功同步的快照。
